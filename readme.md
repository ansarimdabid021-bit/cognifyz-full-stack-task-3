\# 🚀 Cognifyz Full Stack Development Internship – Task 3



\## 📌 Project Overview



This project is developed as part of the \*\*Cognifyz Full Stack Development Internship – Task 3\*\*.



The main objective of this task is to create a modern, responsive and interactive webpage using \*\*HTML, CSS, JavaScript and Bootstrap\*\*.



The website is designed with a clean UI, responsive layout, smooth animations, interactive elements and mobile-friendly navigation.



\---



\## 🎯 Task Objectives



\- Create a complex webpage layout with multiple sections.

\- Implement advanced CSS styling.

\- Add transitions and animations.

\- Make the website fully responsive.

\- Use Bootstrap for a consistent responsive UI.

\- Add JavaScript-based user interaction.



\---

\- 📱 Fully responsive design
